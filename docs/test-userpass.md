# テスト環境 ログイン情報

試験環境用のログインIDとパスワードのリストです。今回は試験環境のため、管理画面から新規追加したユーザー情報はリロードするとリセットされますが、以下の3ユーザーは初期データとして常に利用可能です。

| 権限 | ユーザーID | パスワード | 概要 |
| :-- | :-- | :-- | :-- |
| **院長** (admin) | `admin` | `password123` | 全機能へのアクセス権限および、ユーザー管理（追加）権限を持ちます。 |
| **歯科医師** (doctor) | `doctor1` | `password123` | カルテ（SOAP）の閲覧・編集を含む、システム管理以外の全機能へのアクセスが可能です。 |
| **受付スタッフ** (staff) | `staff1` | `password123` | ダッシュボードと顧客管理（CRM）へのアクセスが可能です。カルテの詳細などは閲覧できません。 |
