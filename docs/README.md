# Dental Hub EMR & CRM

「Dental Hub」は、歯科医院における日常業務をスムーズにし、患者とのつながりを可視化・強化するための次世代型ハイブリッド管理（顧客管理＋電子カルテ）アプリです。

本アプリ一つで、受付から診療、マーケティングに至るまで、以下のことがシームレスに実現できます。

---

## 💡 このアプリでできること

### 1. 安全なアクセス管理による「患者プライバシーの保護」
それぞれの役職に合ったIDでログインすることで、自動的に情報の見え方が変わります。
- **院長・医師**: カルテの入力からシステム全体の設定まですべての機能が使えます。
- **受付スタッフ**: 顧客リストや連絡先は確認できますが、デリケートなカルテ情報へのアクセスはシステムが自動でブロックし、プライバシーを保護します。

### 2. 全体をひと目で把握できる「ダッシュボード」
- アプリにログインして最初に表示されるホーム画面（ポータル）として機能します。
- 一日の業務の起点となり、患者の動向や基本情報を俯瞰して確認できるよう設計されています。（※プロトタイプ版のため現在ホーム枠として準備中）

### 3. 直感的な「顧客管理（CRM）」と患者属性の把握
- 新しく来院された患者をスムーズに登録し、顧客リスト（CRM）として一覧管理できます。
- 名前や電話番号での「検索」や、新患・定期検診など状態に合わせた「絞り込み」が一瞬で行えます。
- 「インプラント検討中」「小児・歯医者嫌い」など、患者一人ひとりの特徴を**タグ付け**しておくことで、次回以降の対応に素早く活かすことができます。

### 4. ビジュアルで入力しやすい「カルテ管理（SOAP）」
- 過去の治療履歴（カルテ）を日付ごとにタイムライン形式で一目で振り返ることができます。
- **インタラクティブ歯式ツール**を搭載しており、画面上の「歯のイラスト」を直接クリックするだけで「どの歯が虫歯か」「どこを治療したか」をビジュアルで入力・記録できます。
- 同時に「患者の主訴（S）」「所見（O）」「診断（A）」「計画（P）」などの専門的な情報を分かりやすいフォーマットで記録します。カルテ作成時にステータス（新患・中断など）を更新すると、顧客管理のリストにも自動で反映されます。

### 5. 紹介による広がりが見える「ネットワーク可視化」
- **「誰が誰を紹介してくれたか」** という患者同士のつながり（家族や友人）を、グラフィカルな樹形図（ネットワークグラフ）で表示します。
- これにより、「どの患者さんが一番他の患者さんを連れてきてくれているか（ハブ患者）」が一目でわかります。紹介してくれた方へのお礼や、再来院を促すマーケティング戦略として絶大な威力を発揮します。

### 6. シンプルな「スタッフ権限・アカウント管理」
- システム管理画面から、新しいスタッフが入社した際のアカウントを簡単に発行できます。
- パスワードと権限（受付・医師など）を設定するだけで、すぐにスタッフが業務に合わせて本アプリを利用開始できます。

### デモとしての利用方法（テスト環境）
本ファイルに併記されている「テスト環境用アカウント（例: `admin` など）」を使ってログイン画面からお好きな権限でログインし、顧客の登録やカルテの作成、紹介ネットワークの様子を実際にクリックして体験してみてください！
